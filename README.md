# Implementation of “TESS: LLM-guided Translation, Exploration, Simulation, and Search for Embodied Task Planning”

This is the Python implementation of the paper "TESS: LLM-guided Translation, Exploration, Simulation, and Search for Embodied Task Planning"

## Environment

Please run the following command to prepare the environment.

```sh
pip install rapidfuzz openai numpy
```

## Data

We provide a demo test set in tinytest_full.pik. It contains 10 task instances, and each on them has the following structure.

```json
{
    "task_id": 1,
    "task_name": "clean_A", // name of the task template
    "env_id": 0, // apartment id in VirtualHome
    "init_graph": { // the initial environment's scene graph 
        "nodes": [],
        "edges": [],
    },
    "task_goal": {
        "grounded_task_name": "Wipe down mug-267 and make sure it’s clean.", // task instruction
        "predicates": [ // goal conditions
            "clean_267",
        ],
    }
}
```

The procedure for data generation and the full-scale dataset will be released on Github.

## Running the Agent

Please fill a valid OpenAI API key in test_agent_VH_graph.py, then use

```sh
python test_agent_VH_graph.py
```

to run the TESS-GPT agent on the provided test set. Hyperparameters in arguments.py can be modified. By default, the generated plans will be saved under "./save_results".

The codes for Qwen-based agent and evaluation on ALFWorld will be open-sourced on Github.

## File Structure

The codes under `agents/` are the implementation of the plan generation algorithm.

The codes under `runners/` are wrappers of the environment, which will execute the plans generated by the agent and receive observations from the environment.

The codes under `simulators/` are the generated precondition and effect functions for the simulation module.

The codes under `utils/` are helper functions that analyze and modify the environment scene graphs, or interact with the LLMs.

Files under `VH_envs/` are basically copied from https://github.com/xavierpuigf/virtualhome/tree/master/virtualhome. They are the Python implementation of VitualHome's evolving graph simulator.
